### Descrição

Projeto desenvolvido durante a **Next Level Week Unite (NLW Unite)** da **Rocketseat** que implementa uma interface web com formulário de inscrição e registro de participantes, exibindo dados de inscrição e check-in de usuários em uma tabela.  
A página está disponível em:  

<img src="https://media.giphy.com/media/v1.Y2lkPWVjZjA1ZTQ3bzRpbmliemhwODBzbWVhaXlhMjR0azN5aW93eDE3YXd2dmozMHpwOCZlcD12MV9zdGlja2Vyc19zZWFyY2gmY3Q9cw/MTt7Eh8WPudlStuY7L/giphy.gif" alt="GIF" width="35" /> https://marcia-vitoria.github.io/nlwunite-projeto/

---

### Tecnologias

- HTML
- CSS
- JavaScript

---

### Funcionalidades

- Formulário de inscrição de participante
- Registro automático de data de inscrição
- Exibição de participantes e datas de check-in em uma tabela
- Interface web responsiva básica

---

### Como executar

#### Localmente
1. Clone o repositório:
```bash
git clone https://github.com/marcia-vitoria/nlwunite-projeto.git
```
2. Acesse a pasta do projeto:
```bash
cd nlwunite-projeto
```
4. Abra o arquivo `index.html`
 em um navegador web.
